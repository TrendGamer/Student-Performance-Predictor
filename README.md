# Student Performance Predictor

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue)](https://www.python.org/) [![Streamlit](https://img.shields.io/badge/App-Streamlit-ff4b4b)](https://streamlit.io/) [![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

A beginner-friendly regression project that estimates an academic score from study time, attendance, previous score, sleep, assignment completion, and extracurricular participation. It demonstrates the full data-to-app workflow using Python, pandas, scikit-learn, and Streamlit.

> **Educational demo:** the included data is synthetic, generated by a documented rule with added random noise. It is not evidence about real students and must not be used for grading, admissions, or other consequential decisions. Predictions are estimates, not definitive judgments.

## Project objectives

- Practice data cleaning, exploratory analysis, regression, model evaluation, and model serialization.
- Compare a simple linear model with a Random Forest on a held-out test set.
- Explore the result with an interactive local web app.

## Key features

- Reproducible synthetic CSV with deliberately introduced missing feature values and duplicate rows.
- Notebook charts for study time, attendance, feature correlations, and score distribution.
- Preprocessing inside scikit-learn pipelines, so imputation and encoding are applied consistently at prediction time.
- MAE, MSE, RMSE, and R² computed on a fixed holdout split. The winning model is selected by lower MAE (RMSE breaks ties); actual results are written to `models/evaluation_metrics.json` when training runs.
- Streamlit form with score estimate, illustrative category, and clear limitations.

## Technologies

Python, pandas, NumPy, Matplotlib, Seaborn, scikit-learn, Streamlit, Joblib, Jupyter.

## Dataset

`data/student_data.csv` is generated locally by `src/generate_data.py` using a fixed random seed. All six feature columns and the target `academic_score` are documented in the generator. The target is produced by a transparent weighted formula plus random noise and clipped to 0–100. A few feature values are set missing and several rows are duplicated so cleaning can be demonstrated. This data is synthetic; no public real-student dataset is included.

| Column | Meaning |
|---|---|
| `study_hours_per_day` | Reported daily study hours |
| `attendance_percentage` | Attendance from 0 to 100 |
| `previous_exam_score` | Previous score from 0 to 100 |
| `sleep_hours` | Hours of sleep per night |
| `assignment_completion_rate` | Completed assignments, percent |
| `extracurricular_participation` | `Yes` or `No` |
| `academic_score` | Synthetic target score from 0 to 100 |

## Architecture and workflow

1. `src/generate_data.py` writes the reproducible synthetic CSV.
2. `src/preprocessing.py` validates columns, removes exact duplicate rows, and excludes rows without a target.
3. `notebooks/exploratory_analysis.ipynb` explores distributions and relationships.
4. `src/train_model.py` makes a fixed 80/20 split. Pipelines impute missing numeric values with medians, impute categories with the most common value, one-hot encode the category, and scale numeric values for Linear Regression. It compares Linear Regression and Random Forest using holdout MAE, MSE, RMSE, and R².
5. The selected fitted pipeline is saved to `models/student_performance_model.pkl`; measured metrics and split sizes are saved to `models/evaluation_metrics.json`.
6. `app.py` loads the saved pipeline and serves predictions locally.

**Beginner explanation:** Linear Regression learns one weighted contribution per input and fits a straight-line relationship. A Random Forest averages many decision trees, which can capture more complex patterns. MAE gives the typical absolute error in score points; MSE penalizes large errors more; RMSE is in score points; R² describes fit relative to predicting the test-set average. None of these guarantees performance on real students.

## Installation

Python 3.10 or later is recommended. From this folder, create and activate a virtual environment, then install dependencies:

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Generate data and train

```bash
python src/generate_data.py
python src/train_model.py
```

The terminal prints all measured holdout metrics. The same results are stored in `models/evaluation_metrics.json`. Retrain after regenerating the CSV; the app does not retrain at startup.

## Run the app

```bash
streamlit run app.py
```

Open the local URL printed by Streamlit. If the model file is absent, follow the generate/train steps above.

## Explore the notebook

```bash
jupyter notebook notebooks/exploratory_analysis.ipynb
```

Run cells from top to bottom after installing dependencies and generating the CSV.

## Evaluation results

| Model | MAE (points) | MSE | RMSE (points) | R² |
|---|---:|---:|---:|---:|
| Linear Regression | 5.25 | 43.96 | 6.63 | 0.718 |
| Random Forest | 5.71 | 52.16 | 7.22 | 0.665 |

On the fixed 80/20 split (960 training and 240 test rows), **Linear Regression** had the lower holdout MAE and was selected. Scores below are computed outputs, not promised accuracy. They apply only to this synthetic dataset and do not measure real-world academic prediction quality.
